# 3.0.2 contracts

Shared by server (`ops/syrmos-api`), Android/KMP, iOS and web. Golden rules live in fixtures generated by `scripts/generate-302-fixtures.py`:

- `fixtures/closures/effect.json`: closure window and per-station effect
- `fixtures/nearby/coach.json`: walk minutes, coach case, headline, copy variant, guards
- `fixtures/calendar/leave-by.json`: event classifier, arrival buffer, leave-at plan

Every platform implementation must pass every case. Change the generator, not the JSON.

## Localised text object

`{"en": "...", "el": "...", "sq": "...", "it": "..."}`. Clients pick the app language, fall back to `en`, then `el`. Any key may be missing.

## GET /api/closures

Public, cacheable (ETag, `Cache-Control: max-age=60`). Returns non-draft, non-cancelled closures whose end is null or later than now minus 24 h.

```json
{
  "schemaVersion": 1,
  "generatedAt": "2026-10-27T18:00:00Z",
  "closures": [
    {
      "id": "syn-parade-2026",
      "stationIds": ["M2_SYN", "M3_SYN"],
      "lineIds": [],
      "mode": "pass_through",
      "startsAt": "2026-10-28T06:00:00Z",
      "startsAtEpochSeconds": 1793167200,
      "endsAt": null,
      "endsAtEpochSeconds": null,
      "status": "scheduled",
      "reason": {"el": "Με εντολή της Αστυνομίας", "en": "By police order"},
      "replacementBus": {
        "label": {"el": "Έκτακτο λεωφορείο", "en": "Replacement bus"},
        "fromStop": {"el": "Σύνταγμα (Αμαλίας)", "en": "Syntagma (Amalias)"},
        "toStop": {"el": "Ευαγγελισμός", "en": "Evangelismos"},
        "headwayMinutes": 10,
        "stops": [{"name": {"el": "Σύνταγμα"}, "lat": 37.9755, "lon": 23.7356}]
      },
      "source": "admin"
    }
  ]
}
```

- `mode`: `closed` | `pass_through` | `exit_only` | `entry_only`.
- `status` is informational; clients must evaluate the window themselves with the fixture rules (so an 08:00 closure flips at 08:00 offline).
- `lineIds` empty = every line at those stations.
- `replacementBus` may be null; `stops` may be empty; `headwayMinutes` may be null and `fromStop` / `toStop` may be `{}` (STASY drafts, admin saves without a headway). Clients omit the missing parts.
- STASY nightly closures ("closes at 21:40 from the 25th to the 29th") become one draft closure per night, since a closure has a single window.
- The seed bundle carries `closures.json` with the same shape as an offline fallback.

## GET /api/broadcasts?since=<epochSeconds>

Public, cacheable. Returns broadcasts with `sentAt >= since` that have not expired, newest first, max 50.

```json
{
  "schemaVersion": 1,
  "broadcasts": [
    {
      "id": "b_01J...",
      "title": {"el": "28η Οκτωβρίου", "en": "28 October"},
      "body": {"el": "Από τις 08:00 ο σταθμός Σύνταγμα είναι κλειστός...", "en": "..."},
      "audience": "all",
      "sentAt": "2026-10-27T18:00:00Z",
      "sentAtEpochSeconds": 1793124000,
      "expiresAt": "2026-10-28T22:00:00Z",
      "expiresAtEpochSeconds": 1793224800,
      "deepLink": "syrmos://station/M2_SYN",
      "closureId": "syn-parade-2026"
    }
  ]
}
```

- `audience`: `all` | `line:<lineId>` | `station:<stationId>` | `region:athens` | `region:thessaloniki`. Clients show a broadcast when the audience is `all`, matches a favourite line/station, or matches the selected region.
- Polling fallback: on app open and background refresh, clients fetch since the last seen `sentAtEpochSeconds`. For unseen broadcasts that were not delivered by push (id not in the delivered set) and are not expired, the client posts one local notification. Dedupe by `id`.

## POST /api/push/register

```json
{"token": "<apns hex or fcm token>", "platform": "ios", "environment": "production", "lang": "el", "topics": ["all", "region.athens", "line.M3", "station.M3_NIK"], "appVersion": "3.0.2"}
```

- `platform`: `ios` | `android`; `environment`: `sandbox` | `production` (iOS only, Android always `production`).
- `204` on success; `400` on bad shape; rate limited (30/hour per IP). Idempotent upsert keyed by token hash. No account, no location, no identifiers other than the token.
- Clients re-register on token change, language change, favourites change, and at most once a day otherwise.

## POST /api/push/unregister

`{"token": "..."}` -> `204`. Called when the user turns off "Announcements from Syrmos".

## Push payload

APNs:
```json
{"aps": {"alert": {"title": "...", "body": "..."}, "sound": "default", "thread-id": "syrmos.broadcast"}, "broadcastId": "b_01J...", "deepLink": "syrmos://station/M2_SYN"}
```
FCM HTTP v1: `message.notification {title, body}` plus `message.data {broadcastId, deepLink}`, Android channel `syrmos_broadcasts`.

Text is chosen server side from the device's registered `lang` (fallback en, el). Clients add the received `broadcastId` to the delivered set so polling does not duplicate it.

## Admin (private)

`/admin/closures`, `/admin/broadcasts`, `/admin/push` behind Cloudflare Access. The server verifies the `Cf-Access-Jwt-Assertion` JWT (RS256 against `https://<team>.cloudflareaccess.com/cdn-cgi/access/certs`, `aud` = `CF_ACCESS_AUD`) and requires the email in `ADMIN_EMAILS`. `HTTP_ADMIN_TOKEN` remains a fallback only when explicitly set. Secrets live in `admin.env` on the Pi only: `CF_ACCESS_TEAM`, `CF_ACCESS_AUD`, `ADMIN_EMAILS`, `APNS_KEY_PATH`, `APNS_KEY_ID`, `APNS_TEAM_ID`, `APNS_TOPIC`, `FCM_SERVICE_ACCOUNT_PATH`, `FCM_PROJECT_ID`.

## Coach copy keys

Case keys from `fixtures/nearby/coach.json`, three variants each (four for `relaxNextOneIsClose`), `{next}`, `{following}`, `{margin}`, `{wait}`, `{line}`, `{destination}` placeholders. Greek seeds (owner tone: friendly, short, a bit playful, never "run"):

| key | el variant 0 | en variant 0 |
|---|---|---|
| relaxNextOneIsClose | Μπορεί το επόμενο για {destination} να έρχεται σε {next}', αλλά το μεθεπόμενο έρχεται σε {following}'. Μην αγχώνεσαι. | The next one to {destination} is in {next}', but the one after is in {following}'. No stress. |
| longGapTakeItEasy | Το τωρινό για {destination} δεν το προλαβαίνεις, το επόμενο σε {following}'. Ώρα για ένα freddo. | You'll miss this one to {destination}; the next is in {following}'. Coffee time. |
| hurry | Για {destination} σε {next}'. Με γρήγορο βήμα το προλαβαίνεις. | {destination} in {next}'. Walk briskly and you'll make it. |
| comfortable | Για {destination} σε {next}'. Φτάνεις άνετα, με {margin}' περιθώριο. | {destination} in {next}'. You'll get there with {margin}' to spare. |
| lastTrain | Προσοχή: το {next}' για {destination} είναι το τελευταίο για σήμερα. | Heads up: the {next}' to {destination} is the last one today. |
| missedLast | Το τελευταίο για {destination} έφυγε. Δες εναλλακτικές στο Syrmos. | The last one to {destination} has gone. Check alternatives in Syrmos. |
| stationClosed | Ο σταθμός είναι κλειστός τώρα. Δες τη διαδρομή αντικατάστασης. | The station is closed right now. See the replacement route. |
| noService | Δεν υπάρχει δρομολόγιο για {destination} αυτή την ώρα. | No service to {destination} right now. |

Times are labelled "κατά πρόγραμμα" / "scheduled" unless the departure is live.

Calendar copy keys: `calendar.headsUp`, `calendar.leaveNow`, `calendar.flightChecklist`, `calendar.late`, per event kind where it reads better (e.g. flight: "Ώρα να φύγεις! Η πτήση δεν περιμένει, το {line} όμως έρχεται σε {next}'.").
