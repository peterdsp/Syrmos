## Priority 1 — complete OSETH integration from the real API

Use the official OSETH web telematics API and the supplied route contract, for example:

```text
https://oseth.com.gr/el/telematics-api/route/01_7429_2_3/info?shapeId=5284&language=el
```

Do not reuse the obsolete `api.oseth.gr` or OASA `act=getStopArrivals` assumptions.

Implement:

1. A small OSETH client for route-instance metadata, stops, shape, live arrivals, and vehicle positions using the actual network requests made by the official site.
2. Route discovery for the Thessaloniki airport services from official response data. Route IDs must be the real route-instance IDs, not invented numeric codes.
3. Airport-stop identification from the official stop catalogue or response payload. Do not keep `THS_AIR` unless the upstream payload proves it.
4. Parsing tests using captured, source-labelled OSETH fixtures. Fixtures must include the original URL, capture date, response shape, and attribution.
5. Explicit freshness and unavailable behavior when OSETH is down. Empty arrays must not be presented as live success.
6. Provenance documentation in `docs/data/airport-bus-provenance.md` with verified endpoint, route, stop, and schema evidence.

**Pass criteria:** a Pi-side command fetches a real OSETH response, produces at least one correctly attributed route/stop record, and the watcher snapshot distinguishes OSETH `live` from `unavailable`.

## Priority 2 — make every airport-bus endpoint snapshot-only

Audit `ops/syrmos-api/syrmos_admin/app.py` and remove provider calls from all airport-bus handlers, including:

- `/api/airport-buses`
- `/api/airport-buses/{operator}`
- `/api/airport-buses/{operator}/{route_id}`
- `/api/airport-buses/{operator}/{route_id}/vehicles`
- `/api/airport-buses/{operator}/{route_id}/alerts`
- `/api/airport-buses/sources`

Handlers must read one validated atomic snapshot, then filter it in memory. They must not instantiate providers or call `fetch_*` functions during an HTTP request.

Add tests that monkeypatch provider fetch methods to fail and prove all endpoint responses still work from a fixture snapshot. Add missing, malformed, stale, and partial-operator snapshot cases.

**Pass criteria:** a source scan finds no provider fetch call in endpoint handlers; endpoint tests pass with upstream networking disabled.
