# 3.0.0 Finding 8 - Greek copy review pack

Status: **reviewed and applied** (native reviewer approved in-session, 2026-09-16).
Every Greek DISPLAY string the detector flagged now carries correct monotonic
accents: the count went from 245 to **0** display candidates, with only the
Ariadne match-key cues (`fastestCues` / `fewestChangesCues` in `AriadneDomain.swift`,
`AriadneParser.swift`) and legitimate all-caps deliberately excluded. Corrections
were applied by exact-literal match, one drafted correction per string, preserving
interpolations (`\(...)`), proper names (Ichnos, Syrmos, Apple Pay, GPS, M3, ...)
and line ids. The iOS app builds clean after the change.

## Method

- **Detector**: `scripts/greek-copy-audit.py` flags Swift string literals with 8+
  Greek letters that carry no accent at all, excluding `AriadneParser.swift` (its
  unaccented strings are search match keys, not display text) and all-caps Greek
  (which legitimately drops the tonos, finding 9). This is a *candidate* detector
  for review, never a certifier of correct Greek: it cannot judge grammar, tonos
  placement, or partial errors, and it over-includes on purpose.
- **Inventory totals**: the previous audit reported 254 of 802 eligible iOS
  literals (~31%) unaccented. This is the historical count, not a new measurement.
  The detector reported **245** at the start of this pass and **0** display
  candidates after review (only excluded match keys / all-caps remain).
- **Reviewer**: native Greek speaker, in-session (product owner), 2026-09-16.

## Guardrails observed

- No indiscriminate accent-insertion or replacement script was run. Every applied
  correction was chosen by hand as a display string with a single unambiguous
  monotonic accentuation.
- Match keys are preserved unaccented. `AriadneParser.swift` and the
  `AriadneDomain.swift` intent cues normalize user input and must stay unaccented;
  the detector rows in those files are listed as **match-key candidate (exclude)**.
- Search still accepts accented and unaccented input (folding in
  `StationGrouping.fold` and the Ariadne normalizer).
- The finding 9 `uppercasedForDisplay` correction and the all-caps vs title-case
  distinction are untouched.
- Interpolation tokens (e.g. `\(tempStr)`) and proper names are preserved.

## Deliberate exclusions (correct as unaccented)

- `AriadneParser.swift` and `AriadneDomain.swift` cue lists (`fastestCues`,
  `fewestChangesCues`, ...): accent-folded, lowercased match keys for user input,
  never display text. Both are excluded in the detector.
- Monosyllables ("δυο", "τι", the article "η"/"Η") and all-caps labels: unaccented
  is correct in monotonic Greek.
