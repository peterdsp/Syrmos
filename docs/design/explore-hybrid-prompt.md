# Syrmos Explore Hybrid Concept Prompt

Use case: ui-mockup

Asset type: high-fidelity portrait iPhone app screen

Primary request: Design one cohesive Syrmos Explore screen that combines a context-aware Now Lens, Ariadne's route-thread metaphor, and an inspiring but practical Journey Deck for regional rail travel.

Product goal: Replace a static destination catalogue with a decision surface that answers where the traveller can realistically go from their current location now, how long the journey will take, when the next service leaves, what it may cost, how many transfers are required, and whether each value is live or approximate.

Visual style: Realistic, shippable iOS product UI. Warm off-white background, crisp dark typography, white rounded cards, subtle shadows, restrained Athens rail green, blue, and purple accents. Use Ariadne's thread as a thin route line with station nodes. Keep the interface calm, accessible, and operational rather than futuristic or decorative.

Screen structure:

1. Compact header titled "Eksploro".
2. Conversational search field reading "Ku dëshiron të shkosh?".
3. Context controls reading "Nga Kallithea", "Tani", and "Deri 45 min".
4. Main recommendation card labeled "Zgjedhja më e shpejtë" for "Monastiraki".
5. Inside the recommendation card, show a compact Ariadne route thread from "Kallithea" to "Monastiraki", with intermediate station nodes and an M1 badge.
6. Show practical metrics prominently: "18 min", "M1 në 3 min", "€1,20", and "Pa ndërrim".
7. Add a confidence strip reading "Orar dhe çmim i përafërt" so estimated data is never presented as guaranteed.
8. Add one clear primary action titled "Nis udhëtimin".
9. Below the main recommendation, add a section titled "Eksploro më larg".
10. Feature a Journey Deck card for "Meteora / Kalambaka" with a restrained scenic illustration and metrics "3 h 48 min", "nga €18", "1 ndërrim", and "Orar i përafërt".
11. Preserve the Syrmos five-tab bottom navigation and Ariadne owl button with enough safe-area clearance that no content is obscured.

Interaction intent: Search changes the destination. Context controls change the starting station, departure time, and travel-time budget. Tapping the route thread expands it into the Map tab. The main action starts guided journey mode. Regional cards open full itinerary and fare details.

Constraints: Use Albanian text exactly as quoted where possible. Show only one chevron or primary action per destination. Transit information must be more prominent than travel imagery. Make uncertainty visible. Avoid glass overload, tourism-booking styling, duplicate controls, tiny labels, fake live claims, unrelated branding, and watermarks.
